# Workflow audit — 2026-10-08

The audit reviewed the local source from setup/imports through planning, model routing, agent tools, approvals, workflows, worktrees, retrieval, persistence/recovery, dashboard, editors, native packaging and optional integrations. It preserved the existing workspace, installed runtimes, grants and trailing-space path. It was not a full audit of every upstream dependency or a production security certification.

## Findings fixed

| Area | Finding and change |
| --- | --- |
| Approval cancellation | File writes, commands, MCP connections/calls and workflow gates now recheck cancellation after approval; an approval arriving after cancellation cannot start the next action. |
| Shutdown | The server stops accepting work, cancels jobs/approvals and drains execution before closing. CLI SIGINT/SIGTERM now uses that path so final records and writer-lock cleanup can finish. |
| Terminal lifecycle | Concurrent starts serialize; callbacks belong to their original session; a naturally exited shell can restart. Browser output retention is capped as well as server output. |
| UI polling and requests | Unchanged agent/team choices, approvals, agent cards and history retain their DOM nodes. The visual check reproduced the old dropdown resetting during selection. Tasks now show an explicit status, and planning is disabled while another dashboard job runs. Ordinary URL anchors no longer overwrite the saved login token. Request decoding preserves split Unicode characters and caps bytes rather than JavaScript characters. |
| Native edits | macOS implements the reload/discard confirmation, protects dirty files on close/quit, and avoids preferring an older packaged host over a newer source build. |
| File and state safety | Descriptor reads are bounded even if files grow; hard-linked state and binary text-editor targets are rejected. Protected paths also reject case aliases on default macOS filesystems. Nonblocking opens avoid hanging on special files. Atomic state readers tolerate replacement of the open snapshot. Writes enforce the same 20 MB serialized limit as reads before replacing the prior record and clean up failed temporary writes. |
| Project retrieval | Empty indexes return an empty result; directories replaced with symlinks are refused; malformed vector dimensions fail explicitly. Indexing checks cancellation, bounds traversal, rejects invalid UTF-8, and reports budget/chunk truncation. The old index limit could produce records too large for the state reader. |
| Git helpers | Read-only Git operations can invoke fsmonitor and content filters. Runtime Git operations now disable those programs; custom filters remain unsupported for reviewed automatic merges. |
| Provider outcomes | Token-truncated and content-filtered responses fail explicitly rather than being recorded as successful completion. Truncated MCP results are marked as incomplete and remain valid JSON. |
| Managed integrations | TradingAgents/OpenMontage pin the previously reviewed source commits and check origin/HEAD plus executable availability. Healthy environments are reused; mismatched sources and incomplete environments are left untouched for manual review. Configuration preflights the agent, refuses to overwrite a differing profile, takes a workspace lock and rolls back the profile on an agent-write failure. Windows managed installation fails explicitly instead of claiming support. |
| Diagnostics and documentation | Doctor keeps MCP/application connections with the same name separate, distinguishes unavailable environment grants from mandatory credentials, and includes previously omitted receipts. Stale claims about missing Git history, untested editors and uninstalled integrations were corrected. |

## Remaining work and limits

1. **Distribution:** the `.app` is a CLI-launched native host, not yet a standalone Finder-launchable IDE. A project picker/launcher, bundled runtime, Developer ID signing/notarization, installer/update lifecycle and Windows/Linux desktop releases remain.
2. **External workloads:** selected cloud providers, full-scale research, reliable TradingAgents structured ratings and provider-backed OpenMontage media generation still need scoped live checks and credential/cost choices. REA/Hyper-Extract discovery receipts do not prove every granted tool works. No missing cloud credentials were fabricated or forwarded to new services.
3. **Third-party isolation:** approved applications and MCP servers retain account-level privileges. Source pins do not freeze transitive installer downloads or authenticate every working-tree file. Existing upstream advisories and the earlier ambient-Conda installation side effect still require separate dependency/environment review; this audit did not blindly downgrade that environment.
4. **Storage/scale:** bounded JSON indexes and repeated history scans suit a prototype, not arbitrarily large projects. A database/index backend, incremental retrieval and pagination remain worthwhile. Approval and filesystem checks are not an OS boundary against another process running as the same user.
5. **Editors:** automated ACP tests passed; saved VS Code/Zed host receipts cover demo runs. The VS Code dashboard-launch UX, richer editor workflows and additional versions were not revalidated interactively here.
6. **Workspace portability:** the trailing-space directory and absolute integration paths remain unchanged to avoid breaking current setup. `.nexus` is private ignored state and is not included in Git pushes.

The repository's earlier completion claims should be read within these boundaries. No automatic merge, trading order, paid API invocation or unrequested runtime upgrade was performed during this audit.
