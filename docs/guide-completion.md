# Guide implementation and validation

Implementation follows the user’s instruction to omit components without sufficient value. The release checklist is resolved through tested native implementations and explicit exclusions below; external validation is never relabeled successful. This continues `8991461`; it does not restart or replace the existing runtime. The earlier 0.3.1 decision is historical. The following records the implemented native scope and the supplied guide's optional/external boundaries. It is not a claim that every proposed external editor or every Phase 5 production-readiness gate is complete.

## Validation record

- Full suite: **493 tests; 492 passed, one skipped, zero failed**, after implementation fixes. Log: `/tmp/nexus-040-regression.log` (local verification output, not a distributed dependency).
- Expanded Studio plus Foundry checks: **12 passed**, including actual JPEG/WebP and MOV/WebM paths and source-boundary denials. A valid embedded WebP fixture replaced an unavailable local WebP encoder; no encoder or Python package was installed. Log: `/tmp/nexus-guide-formats-fixed.log`.
- Responsive/accessibility smoke audit: **56 checks passed**, covering all 14 workspaces at 360, 390, 768 and 1280 pixels, with no browser errors. Includes labels, sampled contrast, overflow and keyboard focus; not a complete VoiceOver audit.
- Direct Chrome GUI: command search opened Studio and moved focus; a synthetic source was imported, brightness changed, exact plan approved and a real derivative preview/completed receipt observed. Model/provider behavior was not inferred from those GUI results.
- One regression was found and corrected: media timeout must remain `failed`; only explicit cancellation is `cancelled`. Affected tests passed after the correction. An intermediate Foundry syntax error was also corrected before the passing GUI audit.
- Native app and DMG verification completed: **17 bundle checks and 14 mounted-image/install/upgrade checks passed**; see [0.4.0 validation](release-0.4.0.md). Signing/notarization must never be inferred from build success.

## Scope decisions and blockers

The guide explicitly permits bounded native pilots and a limited preview with clear exclusions. These implementations avoid installing seven large creative applications, a second agent executor, a proxy, or unreviewed downloaded code. Separately installed FFmpeg and Apple PDFKit perform the verified local operations. No ArtCraft, Kanzo, CC Switch, CodeG, iFixAi, Resource2Skill or Astryx source/assets are redistributed by this change. Source review is scoped in [Studio upstream evidence](studio-upstream-sources.json) and [cross-product upstream evidence](guide-upstream-sources.json); interface inspection does not prove runtime compatibility.

The following are **excluded from this local release and not claimed validated**: optional third-party engine/editor interoperability; RAW/layered/native document fidelity; hostile-parser OS isolation and GPU/memory quotas; executable skill QA and real-provider effectiveness comparisons; official live subscription/quota validation; whole-account monetary accounting; full assistive-technology/platform/clean-machine certification; Developer ID signing and Apple notarization. External engine/editor installs, a second runtime, executable skill QA (no candidate code is executed), RAW/layered editors and whole-account billing were judged unnecessary for these bounded features. Live vendor identity/allowance checks, signing/notarization and clean-machine certification need appropriate accounts, credentials or target machines. These exclusions do not block a clearly labeled local ad-hoc build. Redaction, unapproved failover, CAPTCHA bypass, token replay, remote board sharing and foreign native-session resume are intentionally not exposed.

Unrelated user video-file changes are preserved and excluded from commits and release staging.
